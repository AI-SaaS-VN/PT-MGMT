# Excel 客户数据结构优化建议

> 本文档针对门店现有 Excel 表格（`物理治疗门店客户信息V1.xlsx`）提出改进建议，
> 并说明如何将历史数据一次性导入 PT-MGMT 系统数据库。

---

## 一、现状问题分析

### 当前表结构

| NO | 会员姓名 | 手机号码 | 购买日期 | 课程种类 | 单价/节数/总额 | 已销课（节） | 未销课（节） |
|---|---|---|---|---|---|---|---|
| 1 | 武允文 | 138xxxx | 2026-01-15 | 康复 | 300/70/21000 | 5 | 65 |
| 5 | PATRICE | 199xxxx | 康复 | ... | 12 | 0 |
| 6 | PATRICE | 199xxxx | 功能 | ... | 8 | 4 |

### 问题清单

| # | 问题 | 影响 |
|---|---|---|
| 1 | **一客多行**：同一客户购买多种课程，每种占一行 | 客户基本信息重复填写，容易不一致 |
| 2 | **复合字段**：`单价/节数/总额` 把三个独立数据合并成字符串 | 无法直接做排序、筛选、汇总计算 |
| 3 | **手机号大量缺失**：约 60% 行无手机号 | 无法通知客户，数据质量低 |
| 4 | **日期格式不统一**：部分单元格为纯数字（Excel 序列号），部分为日期格式 | 导出/跨系统使用时出错 |
| 5 | **无疗愈师列**：疗愈师信息仅出现在 Sheet 名称中 | 多名技师数据合并后无法区分 |
| 6 | **课程类型自由输入**：「康复」「功能」等无标准化约束 | 容易出现「康复 」（多空格）等变体 |
| 7 | **无到期日**：无法主动提醒即将过期的课包 | 客户流失风险 |

## 二、推荐表结构（两张独立 Sheet）

### Sheet 1：客户基础信息

> 每位客户**只有一行**，是客户的"身份证"。

| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|

| 姓名 | 文本 | ✓ | |
| 手机号 | 文本（非数字）| 建议 | 以 0 开头或 +86 前缀时需文本格式 |
| 性别 | 下拉（男/女/未知）| | |
| 生日 | 日期 | | |
| 来源疗愈师 | 下拉 | | 首次接诊的技师 |
| 备注 | 文本 | | |

## 三、Excel 设置技巧

### 1. 课程种类下拉限制（防止手误）

1. 选中「课程种类」整列
2. 数据 → 数据验证 → 允许：序列
3. 来源填入：`康复,功能,筋膜刀,拉伸`

### 2. 手机号格式正确存储

手机号以文本格式存储，避免科学计数法：
1. 选中「手机号」列 → 右键格式单元格 → **文本**
2. 重新输入或粘贴手机号

### 3. 日期格式统一

1. 选中「购买日期」列 → 格式单元格 → 日期 → **YYYY-MM-DD**

## 四、历史数据导入说明

### 对应的数据库表

| Excel Sheet | 数据库表 | 说明 |
|---|---|---|
| 客户基础信息 | `users`（role=customer）| 一行 = 一个用户记录 |
| 课时包记录 | `customer_packages` | 一行 = 一个课包记录 |
| 课程种类（枚举）| `courses` | 脚本自动创建 4 条 |
| 疗愈师 | `users`（role=staff）+ `staff_profiles` | 脚本自动创建 Rebecca |

### 运行导入脚本

```bash
# 在项目根目录执行，确保 Docker 容器和数据库已启动
cd /home/franc/CC-Prj/PT-MGMT
PYTHONPATH=backend venv/bin/python backend/scripts/import_excel.py
```

脚本幂等性：重复执行不会创建重复数据（课程、客户、技师均先查再建）。

### 导入后验证

登录 Swagger（http://localhost:8000/docs）：
1. 先 `POST /auth/wx-login`（或用 admin 账号）获取 token
2. `GET /api/v1/packages` 确认课包数量
3. `GET /api/v1/customers` 确认客户数量

## 五、后续维护建议

1. **新客户**：在管理后台（`POST /api/v1/customers`）录入，系统自动生成 UUID
2. **新课包**：`POST /api/v1/packages`，选择客户 ID 和课程种类
3. **每节销课**：`POST /api/v1/sessions/{id}/complete`，系统自动 -1 剩余节数
4. **Excel 作为备份**：系统上线后，Excel 只作为数据备份使用，以系统为准
